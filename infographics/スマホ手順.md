# スマホだけで図解動画を作る手順

PCの `run.bat` の代わりに、GitHub上で動画を作ります。やることは **Issueにナレーションを書くだけ** です。

| 段階 | 担当 | 内容 |
|---|---|---|
| 素材 | 機械 | 各フォルダの `素材メモ.md`（GitHubアプリでそのまま読める） |
| **ナレーション** | **👤 人** | Issue「🎬 図解動画を作る」に自分の言葉で書く |
| 動画化 | GitHub Actions | 数分でIssueにダウンロードリンクが届く |
| **投稿文・投稿** | **👤 人** | 投稿文を自分で書き、**X公式アプリから手動で投稿** |

---

## 声について（APIキーは任意）

- **何もしなければ**：無料の Open JTalk の声で作ります（少し機械的。字幕は常に入ります）
- **より自然な声にしたい時だけ**：下の手順で Google Cloud のキーを登録すると Chirp 3: HD の声になります（従量課金）

### （任意）音声合成のAPIキーを登録する

スマホのChromeで操作します（PC版表示にすると押しやすいです）。

1. https://console.cloud.google.com/ でプロジェクトを作成（既存でも可）
2. 「APIとサービス」→「ライブラリ」→ **Cloud Text-to-Speech API** を有効にする
3. 「認証情報」→「認証情報を作成」→「APIキー」
4. 作ったキーの「キーを制限」で、API の制限を **Cloud Text-to-Speech API のみ** にする
5. GitHub でこのリポジトリの **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `GOOGLE_TTS_API_KEY`
   - Secret: 3で作ったキー

キーはチャットやIssueには貼らないでください。

---

## 毎回の流れ

1. **素材を読む**：GitHubアプリで `infographics/hormuz-sts/素材メモ.md`（モンゴルは `mongol-empire/素材メモ.md`）を開く
2. **Issueを作る**：Issues → New issue → **「🎬 図解動画を作る」**
   - 動画：作りたい図解を選ぶ
   - ナレーション：**1行＝1場面**。上から場面1、2、3…（場面の一覧は入力欄の説明にあります）
   - 飛ばしたい場面は「-」だけの行にすると無音で約4秒映ります
3. **Submit** → 3〜5分でIssueに「✅ 動画ができました」とリンクが届く（GitHubアプリの通知が来ます）
4. **リンクを開いてダウンロード** → 端末に mp4 が保存される
5. **投稿文を自分で書いて、X公式アプリから投稿**

### 直したい時
Issueの本文を編集して保存すると、同じIssueで作り直します（新しいリンクが届きます）。
終わったIssueはCloseしてください（Close後の編集では作り直しません）。

---

## うまくいかない時
| 症状 | 対処 |
|---|---|
| 何も返ってこない | タイトルが「[動画]」で始まっているか確認（テンプレートから作れば自動で付きます）。リポジトリの持ち主のアカウント以外で作ったIssueは受け付けません |
| ❌ で詳細に `HTTP Error 403` | Text-to-Speech API が有効か、キーの制限が正しいか確認 |
| ダウンロードできない | ブラウザでGitHubにログインしているか確認（非公開リポジトリの場合） |

作った動画はリポジトリの **Releases**（`video-issue-番号`）にも残ります。不要になったら Releases から削除できます。
