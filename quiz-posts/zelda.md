# ゼルダの伝説クイズ（X投稿用・4択投票 15問）

使い方: 1問ごとに「投稿本文」をXに貼り、投票を付けて「投票の選択肢」A〜Dを順に入力。2時間後、その投稿に「正解返信」を返信する。

- 本文・返信は280（全角140字）以内、選択肢は25字以内に収めてあり、無料プランでも投稿できます
- 正解の位置はA〜Dで散らしてあります
- 非公式のファンクイズです（画像・ロゴは使わない）

## 第1問

**投稿本文**
```
すべてはこの1本から始まりました。

シリーズ第1作『ゼルダの伝説』が日本で発売されたのは何年？

正解は2時間後にリプで発表🐹
```

**投票の選択肢（A→Dの順に入力）**
```
1986年
1983年
1989年
1991年
```

**正解返信（2時間後）**
```
正解は「A. 1986年」でした！
ファミコンのディスクシステム用ソフトとして登場しました。

🌰豆知識
ディスクに冒険を記録できたのも当時の新しさでした。
```
