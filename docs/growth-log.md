# 📈 認証済みフォロワーの成長ログ

2026-08-08、収益化の方針を「インプレッション量の最大化」から**認証済みフォロワーの獲得**へ切り替えました。
この文書は、その進捗を測るための記録です。

## なぜ記録するのか

何を変えたら数字がどう動いたかが分からないままでは、次の判断ができないからです。

現時点で信頼できる測定値は **Creator Studio → Original Content Rewards に表示される2つの数字だけ**です。
X Analytics の総インプレッションやいいね数は、この条件の集計とは別物なので代用になりません。

施策の効果を見たいなら、**一度に1つだけ変えて、2週間は同じ条件で回す**のが最低限です。
複数を同時に変えると、どれが効いたのか永久に分かりません。

## 記録の取り方

1. 週1回（曜日を固定する）、Creator Studio → Original Content Rewards を開く
2. 「認証済みフォロワー」と「過去90日間の認証済みインプレッション」の数値を下の表に追記する
3. その週に変えたことがあれば「変更点」に書く。何も変えていない週は「なし」と書く

数値が動かない週が続いても、記録は続けてください。**動かなかったという事実も測定結果です。**

## ベースラインから分かること

測定時点の内訳です。

- 目標まで **認証済みフォロワーはあと387人**（達成率23%）
- 目標まで **インプレッションはあと498,300回**（達成率0.34%・**294倍**必要）

インプレッションについては、90日間で700〜800本投稿して1,700回でした。
**1投稿あたり2〜3回**しか認証済みインプレッションが発生していません。

ここから言えるのは、**投稿本数は制約になっていない**ということです。
本数を倍にしても3,400回にしかならず、50万にはまったく届きません。
効いているのは「1投稿を認証済みユーザーが何人見るか」で、これはフォロワー数と配信力の問題です。

さらに、仮に認証済みフォロワーが500人になり、その全員が毎回の投稿をホームタイムラインで見たと仮定しても、

```
500人 × 9本/日 × 90日 = 405,000回
```

で、50万には届きません。実際には全員が毎回見ることはあり得ないため、
**この基準はフォロワー数千人規模か、フォロー外への大きな拡散が前提**になっています。

したがって当面の目標はフォロワー500人ですが、それは収益化の入口に立つための必要条件にすぎず、
**十分条件ではありません。** 収益化の到達時期は現時点では読めません。

## 注意

- Botの自動投稿は、Original Content Rewards Program では**収益の対象外**です（「created or posted using automated means」）。
  フォロワーが増えても、投稿方法を変えない限り収益にはつながりません。→ [収益化ガイド](pixel10a-x-monetization-guide.md)
- 「投票で答えてね」のような**繰り返しのエンゲージメント誘導**は継続条件で禁止されています。
  クイズの定型文が形式上これにあたるため、収益化を狙う段階では見直しが必要です。
