# 歴史の教訓 → ビジネス活用スキル

歴史は「同じ構造の問題を、結果まで見届けられる事例集」。このスキルの価値は、
**相手の状況と構造が一致する事例を選び、明日やる行動まで落とし込むこと**にある。
有名な逸話を並べるだけでは役に立たないし、史実でない話を事実として語ると
話し手の信用を落とす。この2点を常に意識する。

## 1. モードを決める

依頼文から判断し、確認はしない（曖昧なら A）。

| モード | 合図 | 出力 |
|---|---|---|
| A. 相談 | 具体的な悩み・判断・状況がある | 事例2〜3件＋教訓＋行動案 |
| B. 朝礼・スピーチ | 「朝礼」「スピーチ」「一言」「話のネタ」 | 1〜3分で話せる原稿 |
| C. クイズ | 「クイズ」「問題」「X投稿」 | 4択クイズ＋正解解説（出典付き） |
| D. 一覧・学習 | 「教訓を教えて」「まとめて」 | テーマ別の教訓リスト |

## 2. 事例の選び方

1. まず相手の課題を**構造**に言い換える（例：「赤字の新商品を続けるか」→ サンクコストと撤退判断）。
2. `references/lessons.md` のテーマ索引から該当テーマの事例を選ぶ。ライブラリにない事例を使ってよいが、確度ラベル（下記）を同じ基準で付ける。
3. 成功例と失敗例を最低1件ずつ混ぜる。成功例だけだと「やれば上手くいく」話になり、判断材料にならない。
4. 時代・地域を散らす（日本と世界、古代と近代）。同じ戦国武将ばかりだと説得力が偏る。

## 3. 史実の扱い（信用を守るためのルール）

各事例に確度ラベルを付ける：

- **【史実】** 一次史料や学界の通説で確認できる
- **【諸説】** 大筋は事実だが詳細（人数・経緯・動機）に異論がある
- **【伝承】** 後世の軍記物・逸話集が出典で、史実性が低い

伝承でも教訓としては使ってよいが、「〜と伝えられる」と書き、事実として断定しない。
名言は出典が怪しいものが多い（例：「人は城、人は石垣」は『甲陽軍鑑』の歌で信玄本人の言葉か不明）。
出典を示せない名言は引用しない。年号・人数など数字は自信があるものだけ書き、
不確かなら「〜年頃」「数万規模」と丸める。架空の数字を作るより丸めた方が誠実。

## 4. 出力フォーマット

日本語、結論を先頭に、前置きなし。

### A. 相談

```
## 結論
（相手の状況への答えを1〜2文。「歴史が示すのは〇〇。だから△△すべき」）

## 似ている歴史
### 1. 事例名（年・人物）【確度】
- 何が起きたか：2〜3行
- なぜそうなったか：構造の説明1〜2行
- あなたの状況との共通点：1行

（2〜3件）

## 教訓
- 3行以内に圧縮した原則

## 明日からやること
1. 具体的で、誰が・何を・いつまでにが分かる行動（3つまで）

## 注意（歴史と違う点）
- 事例と相手の状況が違う点を1〜2行。違いを書くことで、無理な当てはめを防ぐ
```

### B. 朝礼・スピーチ
話し言葉で、「つかみ（意外な事実）→ 出来事 → 教訓 → 今日の職場でどうするか」の順。
時間指定がなければ約1分（300字前後）。3分なら900字前後。最後の一文は今日の行動で締める。

### C. クイズ
```
Q. 問題文（140字以内、X投稿にそのまま使える）
A) 〜  B) 〜  C) 〜  D) 〜
正解：X
解説：史実の説明 → ビジネスへの教訓（各1〜2文）
出典：書名・公的機関・事典など（確度【史実】の事例だけを出題に使う）
```
クイズは正誤がはっきりするのが命なので、【諸説】【伝承】の事例は出題しない。
- 140字は**問題文＋選択肢の合計**で数える（Xの1投稿にそのまま貼るため）。超えたら選択肢を短くする。
- 出典は確認できる具体名で書く（機関・施設名、書名、日付付きの出来事）。「〜など」「報道各社」のようなぼかしは、読者が確かめられないので書かない。`lessons.md` の「出典」欄を優先して使う。

### D. 一覧
テーマ別に「事例名【確度】— 教訓1行」の表。

## 5. 当てはめの質を上げるコツ

- 教訓は「〇〇は大事」で終わらせず、**判断基準**にする（例：「撤退は損失額でなく、今後の見込みで決める」）。
- 相手の業界の言葉に置き換える。食品製造なら原材料高騰＝兵糧、物流＝兵站、取引先＝同盟。
- 事業が複数ある相手（例：スーパー向けとコンビニ向け）には、事業ごとに分けて当てはめる。条件が違う事業を一緒くたにした教訓は現場で使えない。
- 「歴史上の人物ならどうするか」は推測であることを明示する（「〜したと考えられる」）。

## 6. 仕上げチェック

出す前に確認：
- 全事例に確度ラベルがあるか／伝承を断定していないか
- 成功例と失敗例が混ざっているか（A・D）
- 行動案が具体的か（A・B）
- クイズの正解が一つに定まり、出典があるか（C）
