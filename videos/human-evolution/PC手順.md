# PCで教材動画を作る手順（Windows）

| 段階 | 内容 |
|---|---|
| 台本 | `script.json`（タイトル・各場面の見出し／字幕／読み上げ文） |
| 素材 | 場面画像 `scenes\NN.png`（`素材プロンプト.md` で生成して置く） |
| 動画化 | `run.bat` でナレーション（Google Cloud Text-to-Speech／Chirp 3: HD）・BGM・字幕・映像を合成 |
| 出力 | `out\<動画名>_日付_時刻.mp4` |

---

## 初回だけ

### 1. Python を入れる
1. https://www.python.org/downloads/ から Python 3.11 以降をインストール
2. インストーラの最初の画面で **「Add python.exe to PATH」にチェック**

### 2. このフォルダを PC に置く
受け取った ZIP を右クリック →「プロパティ」→「許可する」にチェック → OK → 展開します（例: `C:\動画\<動画名>`）。
以降はこのフォルダで作業します。更新版を受け取ったら、同じ場所に上書きで展開します（`.env` は消えません）。

### 3. Google Cloud の API キーを用意する
**以前の教材動画・モンゴル帝国の動画で使ったキーがある場合**はそのまま使えます（前の動画フォルダの `.env` の `GOOGLE_TTS_API_KEY=` の行をコピー。Windows の環境変数に設定済みなら `.env` への記入も不要）。
キーの値は https://console.cloud.google.com/apis/credentials の「キーを表示」でも確認できます。

新しく作る場合:
1. https://console.cloud.google.com/ でプロジェクトを作成（既存でも可）
2. 「お支払い」でプロジェクトに請求先アカウントを紐づける（無料枠内でも登録が必要）
3. 「APIとサービス」→「ライブラリ」→ **Cloud Text-to-Speech API** を有効にする
4. 「認証情報」→「認証情報を作成」→「APIキー」
5. 作ったキーの「キーを制限」で、API の制限を **Cloud Text-to-Speech API のみ** にする（漏れた時の被害を抑えるため）

### 4. `.env` を作る
`.env.example` をコピーして `.env` という名前にし、`GOOGLE_TTS_API_KEY=` の後ろにキーを貼ります。
すでに `.env` がある場合は、メモ帳で開いて `GOOGLE_TTS_API_KEY=キー` の1行を足すだけで構いません（Gemini の行は残しても使われません）。

`.env` はこのPCの中だけで使います。チャットやメールには貼らず、スクリーンショットにも写さないでください。

### 5. 診断する（うまくいかない時もまずこれ）
**`check.bat` をダブルクリック**。フォント・ライブラリ・APIキー・音声1回分の合成を順に確認し、
最後に「診断はすべて正常です」と出れば準備完了です。止まったら表示された「エラー:」の行を確認してください。

---

## 毎回の流れ

1. （任意）新しい場面画像を `scenes\NN.png` として置く（NN は `素材プロンプト.md` の番号）
2. （任意）画面の確認：`cmd` で `run.bat preview` → 各場面の静止画 `preview_00〜12.png` ができます（API は使いません）
3. **`run.bat` をダブルクリック** → 10分前後で `out\<動画名>_日付_時刻.mp4` ができます
   - 動画の長さはナレーションの長さに合わせて自動で決まります
   - `.env` に `VIDEO_OUT_DIR=G:\マイドライブ\X投稿` のように書くと、最初からドライブに出力できます

## ナレーションの文面・読み方を変えたい
`script.json` をメモ帳で開き、各場面の `"sub"` が字幕、`"read"` が読み上げ文です（保存は UTF-8 のまま）。
- 読み間違いは 3列目をひらがなにして直します（例: 元 → `げん`、上都 → `じょうと`）
- 文面を変えると、その場面だけ API で作り直します（変えていない場面は `.cache` を再利用）

## 声を変えたい
`.env` に `TTS_VOICE=ja-JP-Chirp3-HD-Aoede` のように書きます（男性: Charon・Puck など、女性: Aoede・Kore など）。

## 料金の目安
読み上げは1本（約2分）で約600字です。Chirp 3: HD の月あたりの無料枠に十分収まる量です（推定。最新の料金は Google Cloud の料金ページで確認してください）。
同じ文面・同じ声は `.cache` に保存され、2回目以降は API を呼びません。

## Gemini で読み上げたい場合
AI Studio でクレジットを追加したうえで、`.env` に `TTS_ENGINE=gemini` と `GEMINI_API_KEY=キー` を書きます（無料枠では音声生成は使えません）。

## うまくいかない時
| 症状 | 対処 |
|---|---|
| `GOOGLE_TTS_API_KEY が未設定です` | `.env` の名前（`.env.txt` になっていないか）と中身を確認。エクスプローラーの「表示」→「ファイル名拡張子」にチェックすると本当の名前が見えます |
| `HTTP 403` | Cloud Text-to-Speech API が有効か、プロジェクトに請求先アカウントが紐づいているか、キーの制限に Text-to-Speech が含まれるか |
| `HTTP 400` で声の名前のエラー | `TTS_VOICE` の綴りを確認 |
| `接続できません` | ネット接続、会社のプロキシ・セキュリティソフトが Google への通信を止めていないか |
| `Python not found` | Python を入れ直し、「Add python.exe to PATH」にチェック |
| `HTTP 429` | 回数制限。自動で待って再試行します。止まった場合は少し時間をおいて再実行（済んだ場面は `.cache` から再利用） |
| 文字が □ になる | Windows 10/11 標準の「BIZ UDゴシック」「游ゴシック」を使います。入っていなければ Windows Update で日本語フォントを追加 |
| それ以外 | フォルダにできる `エラーログ.txt` の中身を送ってください（APIキーは含まれません） |
