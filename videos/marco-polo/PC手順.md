# PCでマルコ・ポーロ物語の動画を作る手順（Windows）

| 段階 | 内容 |
|---|---|
| 素材 | 絵巻 `scroll.jpg` と場面画像 `scenes\NN.png`（`素材プロンプト.md` で生成して置く） |
| 動画化 | `run.bat` でナレーション（Gemini API）・BGM・字幕・映像を合成 |
| 出力 | `out\marco_polo_日付_時刻.mp4` |

---

## 初回だけ

### 1. Python を入れる
1. https://www.python.org/downloads/ から Python 3.11 以降をインストール
2. インストーラの最初の画面で **「Add python.exe to PATH」にチェック**

### 2. このフォルダを PC に置く
チャットで受け取った `marco-polo.zip` を展開します（例: `C:\動画\marco-polo`）。以降はこのフォルダで作業します。

### 3. 必要なライブラリを入れる
フォルダのアドレスバーに `cmd` と入力して Enter → 開いた黒い画面で:
```
py -m pip install -r requirements.txt
```

### 4. Gemini の API キーを用意する
1. https://aistudio.google.com/apikey を開き、Google アカウントでログイン
2. 「APIキーを作成」→ 表示されたキーをコピー
3. `.env.example` をコピーして `.env` という名前にし、`GEMINI_API_KEY=` の後ろにキーを貼る

`.env` はこのPCの中だけで使います。チャットやメールには貼らないでください。

---

### 5. 診断する（うまくいかない時もまずこれ）
**`check.bat` をダブルクリック**。フォント・ライブラリ・APIキー・音声1回分の合成を順に確認し、
最後に「診断はすべて正常です」と出れば準備完了です。止まったら表示された「エラー:」の行を確認してください。

---

## 毎回の流れ

1. （任意）新しい場面画像を `scenes\NN.png` として置く（NN は `素材プロンプト.md` の番号）
2. （任意）画面の確認：`cmd` で `run.bat preview` → 各場面の静止画 `preview_00〜12.png` ができます（API は使いません）
3. **`run.bat` をダブルクリック** → 10分前後で `out\marco_polo_日付_時刻.mp4` ができます
   - 動画の長さはナレーションの長さに合わせて自動で決まります（約2分）
   - `.env` に `VIDEO_OUT_DIR=G:\マイドライブ\X投稿` のように書くと、最初からドライブに出力できます

## ナレーションの文面・読み方を変えたい
`make_video.py` の `SCENES`（上の方）で、各場面の 2列目が字幕、3列目が読み上げ文です。
- 読み間違いは 3列目をひらがなにして直します（例: 元 → `げん`、上都 → `じょうと`）
- 文面を変えると、その場面だけ API で作り直します（変えていない場面は `.cache` を再利用）

## 声を変えたい
`.env` に `GEMINI_TTS_VOICE=Kore` のように書きます（男性: Charon・Puck など、女性: Kore・Aoede など）。
話し方は `GEMINI_TTS_STYLE=` に日本語で指示できます（例: 「少しゆっくり、物語を語るように」）。

## 料金の目安
読み上げは全体で約600字、13回の呼び出しです（モデルは既定で gemini-3.8-flash-tts）。無料枠の範囲に収まる可能性が高い量です（推定。最新の料金・無料枠は Google AI Studio で確認してください）。
同じ文面・同じ声は `.cache` に保存され、2回目以降は API を呼びません。

## うまくいかない時
| 症状 | 対処 |
|---|---|
| `GEMINI_API_KEY が未設定です` | `.env` の名前（`.env.txt` になっていないか）と中身を確認。エクスプローラーの「表示」→「ファイル名拡張子」にチェックすると本当の名前が見えます |
| `HTTP 400` / `HTTP 404` | モデル名が合わない。通常は自動で使えるTTSモデルに切り替わります。直らなければ `.env` の `GEMINI_TTS_MODEL=` を消す |
| `HTTP 403` | キーの貼り間違い、またはキーが無効（前後に空白や引用符が入っていないか） |
| `接続できません` | ネット接続、会社のプロキシ・セキュリティソフトが Google への通信を止めていないか |
| `Python not found` | Python を入れ直し、「Add python.exe to PATH」にチェック |
| それ以外 | フォルダにできる `エラーログ.txt` の中身を送ってください（APIキーは含まれません） |
| `HTTP 429` で止まる | 無料枠の回数制限。自動で待って再試行します。止まった場合は少し時間をおいて再実行（済んだ場面は `.cache` から再利用） |
| 文字が □ になる | Windows 10/11 標準の「BIZ UDゴシック」「游ゴシック」を使います。入っていなければ Windows Update で日本語フォントを追加 |
