# マルコ・ポーロ物語 素材プロンプト

生成した画像を `scenes\NN.png`（16:9、1920x1080 以上推奨）として置き、`run.bat` を再実行すると、その場面に反映される。
画像が無い場面は、scroll（1枚絵）があればその切り出し、無ければ見出しを大きく出した仮画面になる。

## 共通（全プロンプトの末尾に付ける）

```
richly detailed historical painting, warm natural light, painterly realistic style like a museum illustration, 13th century, no text, no letters, no captions, 16:9
```

※「no text」は必須（字幕と二重になり、崩れた文字も出やすいため）。
