# 台本（script.json）の書き方

## 目次
1. 形式
2. 構成の目安
3. 字幕（sub）と読み上げ（read）
4. 画像プロンプト
5. 1枚絵（scroll）をカメラでたどる場合

## 1. 形式

```json
{
 "title": "マルコ・ポーロ物語",
 "subtitle": "ヴェネツィアから大ハーンの国へ　二十四年の旅",
 "slug": "marco_polo",
 "speaking_rate": 1.0,
 "tts_style": "歴史ドキュメンタリーのナレーターとして、落ち着いた温かい声で…（Gemini 使用時のみ有効）",
 "credit": "絵: 生成AI画像（史実の考証を経たものではありません）",
 "image_style": "…共通の画風指定… no text, no letters, no captions, 16:9",
 "bgm_prompt": "（任意）Suno 等で BGM を作る場合のプロンプト",
 "scroll": "（任意）scroll.jpg",
 "scenes": [
  {"title": true, "sub": "マルコ・ポーロ物語", "read": "マルコ・ポーロ物語。…"},
  {"head": "1271年 ヴェネツィア", "sub": "字幕の文", "read": "読み上げの文", "image_prompt": "英語の画像プロンプト"}
 ]
}
```

- `slug` は半角英数字と `_` `-` のみ。出力ファイル名と ZIP 名になる。
- `speaking_rate`（任意）は朗読の速さ。1.0 が標準、1.25 で約1.25倍速（Cloud TTS のみ有効。`.env` の `TTS_SPEED` が優先）。
- 場面番号は scenes 配列の順番（00 から）。画像は `scenes/NN.png`。
- 00 は `"title": true` のタイトル場面にする。タイトル場面の画像は、動画全体を象徴する1枚（無ければ仮画面）。
- 完全な例: `assets/example_marco_polo.json`

## 2. 構成の目安

| 長さ | 場面数 | 1場面の読み上げ |
|---|---|---|
| 約1分 | 6〜8 | 30〜50字 |
| 約2分 | 11〜14 | 40〜60字 |
| 約3分 | 16〜20 | 40〜60字 |

1場面あたり、読み上げの長さ＋約2.4秒の間が入る（Cloud TTS で約7字/秒×speaking_rate の推定）。速くした場合は、同じ長さに収めるため読み上げ文を長めにする（1.25倍・3分なら20場面×55字前後）。

流れは「つかみ（タイトル）→ 背景 → 出来事を時系列で → 意外な事実・誤解されやすい点 → 後世への影響・まとめ」にすると、教材として理解しやすい。
年号・人数・距離などの数字は、史実として広く認められたものに限る。諸説ある話は「〜といわれています」と書き、断定しない（伝説を事実として教えないため）。

## 3. 字幕（sub）と読み上げ（read）

見る文字と聞く音で最適な表記が違うので、2つに分ける。

| 字幕（sub） | 読み上げ（read） | 理由 |
|---|---|---|
| 1271年 | 千二百七十一年 | 年号の読み誤り防止 |
| 17歳 | 十七歳 | 同上 |
| 元の夏の都「上都」 | げんの夏の都、じょうと | 元（もと）・上都（うえと）と読まれないように |
| 日本 | にほん | 「にっぽん」との揺れ防止 |
| 『東方見聞録』 | 東方見聞録 | 記号は読まない |

- 読み上げでは、読点「、」で息継ぎの位置を作る。長い文は2文に分ける。
- 歴史の固有名詞（王朝・地名・人名）で音読みが分かれるものは、迷ったら ひらがな にする。
- 字幕は1〜2行（全角50字前後まで）に収める。長いと画面下が埋まる。

## 4. 画像プロンプト

- 英語で書く（画像生成AIの精度が高いため）。
- 各場面は「誰が・どこで・何をしている・時代・印象的な小物」を1文で。
- 共通の画風（image_style）を全場面の末尾に付けて、場面ごとの画風のばらつきを抑える。
- **`no text, no letters, no captions` は必須**。画像内の文字は崩れやすく、字幕とも重なる。
- 16:9、1920x1080 以上を推奨。小さい画像は引き伸ばしでぼやける。
- 実在人物の肖像は「当時の人物のイメージ」として描かせ、写真風の実写表現は避ける（誤認を防ぐ）。

## 5. 1枚絵（scroll）をカメラでたどる場合

絵巻・地図・インフォグラフィックのような大きな1枚絵がある場合は `"scroll": "scroll.jpg"` を指定し、場面ごとに `camera` を書く:

```json
"camera": [[0.0, 704, 384, 1408], [1.0, 704, 384, 1250]]
```

各要素は `[場面内の時間の割合(0〜1), 注目点x, 注目点y, 映す横幅]`（すべて scroll 画像のピクセル）。
場面画像 `scenes/NN.png` があれば、そちらが優先される。camera を省略した場面は、1枚絵全体にゆっくり寄る。
