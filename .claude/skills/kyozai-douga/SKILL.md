# 教材動画生成

テーマ（と任意で手持ちの画像）から、約1〜3分の教材動画を PC で作れる一式を用意する。
動画の書き出しはユーザーの Windows PC で行う（読み上げ API のキーが PC にあり、ユーザーは PC 中心で作業するため）。
Claude は台本・画像プロンプト・プレビュー・ZIP を用意し、PC でのつまずきを一緒に解消する。

## 全体の流れ

1. **台本を作る** → `script.json`
2. **画像を用意する** → 素材プロンプトを渡し、ユーザーが生成した画像を `scenes/NN.png` に置く
3. **プレビューで確認** → 全場面の一覧画像を見せる
4. **ZIP を渡す** → ユーザーが PC で `check.bat` → `run.bat`
5. **仕上げ** → 読み間違い・画像の差し替えを反映して ZIP を渡し直す

## 1. 台本を作る

作業フォルダ（例: `videos/<slug>/`）を作り、`script.json` を書く。書き方は **`references/script_guide.md` を読んでから**書く（字幕と読み上げの書き分け、場面数の目安、画像プロンプトの規則がある）。完全な例は `assets/example_marco_polo.json`。

- 長さの指定が無ければ約2分（12〜13場面）にする。
- 事実は広く認められたものだけにし、伝説や諸説は「〜といわれています」とする。教材として誤りを教えないため。
- 読み上げ文（read）は、読み誤りやすい語（王朝名・地名・年号・日本）を ひらがな／漢数字 にする。ユーザーから読み方の指摘があれば必ず反映する（例: 元＝げん）。
- ユーザーが手持ちの1枚絵（絵巻・地図など）をくれた場合は `scroll` と各場面の `camera` を使うと、画像を生成しなくても最初の版が作れる。

## 2. 画像を用意する

各場面に英語の `image_prompt` と共通の `image_style` を書き、`build_project.py` が `素材プロンプト.md` を作る。チャットでも、場面番号・場面名・プロンプトの表でユーザーに渡す。
ユーザーが画像を送ってきたら、内容を見て場面に割り当て、`scenes/NN.png` として保存する（重複画像は使わない、画風や文字の混入に気づいたら一言伝える）。

## 3. プレビューと ZIP

```bash
python <このスキル>/scripts/build_project.py <作業フォルダ> --preview --zip-dir <送付用フォルダ>
```

- make_video.py と PC 用の付属ファイルをコピーし、素材プロンプト.md を作り、`preview_sheet.png`（全場面の一覧）と `<slug>.zip` を作る。
- script.json・scenes・.env は上書きしない。
- 必要ライブラリ: `pip install numpy scipy pillow imageio-ffmpeg`（初回だけ）。
- `preview_sheet.png` を自分で見て、字幕のはみ出し・画像の割り当て違いが無いか確かめてから、一覧と ZIP をユーザーに送る。
- 渡し直すときは ZIP 名に版を付ける（`<slug>-v2.zip`）。古い ZIP を展開する取り違えが実際に起きたため。

## 4. PC での実行（ユーザー側）

ZIP の中の `PC手順.md` に全手順がある。チャットでは要点だけ伝える:

1. ZIP を右クリック →「プロパティ」→「許可する」にチェック → 展開（更新時は同じ場所に上書き。`.env` は消えない）
2. 初回だけ `.env.example` を `.env` にコピーして `GOOGLE_TTS_API_KEY=` を記入（以前の動画のキーをそのまま使える）
3. `check.bat` → 「診断はすべて正常です」を確認
4. `run.bat` → 10分前後で `G:\マイドライブ\教材動画\<slug>_日付_時刻.mp4`（`.env` の `VIDEO_OUT_DIR`。未設定なら `out\`）。既存の `.env` にこの行が無ければ足してもらう

読み上げは Google Cloud TTS（Chirp 3 HD、既定の声 Charon）。Gemini の音声生成は無料枠では使えない（HTTP 402）ので、ユーザーがクレジットを追加した場合だけ `.env` に `TTS_ENGINE=gemini` を書いてもらう。

## 5. うまくいかない時

Claude から PC の画面は見えない。止まったら「エラー:」の行か `エラーログ.txt` を送ってもらう（APIキーが写らないよう毎回ひと言添える）。
症状別の原因と対処は **`references/troubleshooting.md`** にある（ZIP のブロック、古い ZIP の展開、402、環境変数に残った古いキー など、実際に起きたもの）。

## 仕上げの修正

- 読み間違い → script.json の `read` を ひらがな にして ZIP を渡し直す（変更した場面だけ API で作り直し、他は `.cache` を再利用する）。
- 声を変える → `.env` に `TTS_VOICE=ja-JP-Chirp3-HD-Aoede` など（女性: Aoede・Kore、男性: Charon・Puck）。
- 朗読の速さ → script.json に `"speaking_rate": 1.25` など（`.env` の `TTS_SPEED` でも可）。速さを変えると全場面の音声を作り直す。
- 画像を差し替える → 同じ番号の `scenes/NN.png` を上書き。

## 注意

- 完成した mp4 はリポジトリにコミットしない（数十MBあり、作り直すたびに履歴が重くなる）。出力先の `out/` は .gitignore 済み。
- チャットで送れるファイルは30MBまで。
- APIキーはチャットに貼らない・画面に写さないよう、キーの話が出るたびに伝える。
