# クイズ作成スキル

テーマを受け取り、裏取り済みの4択クイズを作る。出力は必ず下の **出力形式** の順番にする。

## 手順

1. **調べる**：テーマをWeb検索する。1つの数字につき出典を最低1つ確保する。
   - 数字が確定値か、推定・報道ベース・本人の主張かを区別する。
   - 「寄せ集めデータ」「異論の多い数字」は正解に使わない（解説で触れるのは可）。
2. **ネタを選ぶ**：確定値があり、意外性のある事実を優先する。指定がなければ4問作る。
3. **書く**：下の各項目のルールに従う。
4. **検査する**：`scripts/check_quiz.py` で形式と文字数を確認し、全数字を出典と照合する。
5. **出す**：クイズ本文 → 出典一覧 → 検査方法と結果1行、の順で返す。

## 出力形式

```
**Q（番号）**
**問題**：<フック1文> <問い>
**選択肢**：A) …　B) …　C) …　D) …
**ヒント**：<1文>
**解説**：<約300字>
```

### 問題（フックで引き込む）
- 冒頭に読み手を止める一言を置く。型は次のどれか：
  - 自分ごと化：「あなたのメールアドレスも入っていたかも？」
  - 意外性：「実は"新しい流出"ではなかった？」
  - 数字の大きさ：「日本の人口の25倍」
  - 問いかけ：「あなたはいくつだと思う？」
- その後に問いを1文で書く。全体で80字以内。
- 誇張・煽り・事実と違う言い回しは使わない。

### 選択肢（4つ）
- 必ずA〜Dの4つ。正解は1つだけ。
- 数字の問題は桁を散らす（例：3億／10億／30億／300億）。
- ハズレも「ありそう」に見えるものにする。冗談の選択肢は入れない。
- 正解の位置は問題ごとに変える（全部Cにしない）。

### ヒント
- 1文、40字以内。
- 答えを直接言わない。選択肢を2つ程度に絞れる情報にする。
- 出典にある事実だけで書く。

### 解説（約300字）
- 270〜330字（句読点込み）。
- 1文目で「正解は〇、△△です。」と答えを言う。
- 続けて「いつ・どこで・何が起きたか」→「数字の背景や経緯」→「関連する豆知識や注意点」の順。
- 推定値・修正された数字は、その旨を書く。
- 出典で確認できない記述は書かない。迷ったら削る。

## 禁止事項
- 出典のない数字・固有名詞を使う
- 実在の個人を中傷・揶揄する内容
- 答えが2つ以上成り立つ問題

## 検査（毎回必須）
1. `python3 .claude/skills/quiz-maker/scripts/check_quiz.py <クイズを書いたファイル>` を実行し、全問OKにする。
2. 全問の数字・年月を出典と照合する。1件でも合わなければ直してやり直す。
3. 最後に「検査方法と結果」を1行で書く。

## 例

**Q1**
**問題**：あなたのメールアドレスも入っていたかも？ 1社の情報漏洩として史上最大とされる、2013年のYahooの事件。漏れたアカウント数は？
**選択肢**：A) 3億　B) 10億　C) 30億　D) 300億
**ヒント**：最初は5億と発表され、その後2回、数が増やされました。
**解説**：正解はC、30億アカウントです。Yahooは2016年9月、2014年の不正アクセスで約5億アカウントの情報が漏れたと発表しました。同じ年の12月には、それとは別の2013年の事件で約10億アカウントが漏れたと公表します。さらに2017年10月、追加の調査で、2013年の事件では当時あった全30億アカウントが影響を受けていたと修正しました。発表のたびに数が増えた珍しい例です。1社で起きた1つの事件としては、今も史上最大とされています。なお2025年に話題になった「160億件」のように、もっと大きな数字のニュースもあります。ただしそれは過去の流出データを集めたもので、1つの事件ではありません。
